# 📚 OpenMind Technical Documentation Suite

Chào mừng bạn đến với trung tâm tài liệu kỹ thuật của dự án **OpenMind** — Trợ lý học tập thông minh ngoại tuyến (Offline AI Learning Assistant).

Thư mục này tập hợp toàn bộ hồ sơ kỹ thuật, kiến trúc, đặc tả API và hướng dẫn biên dịch mã nguồn theo chuẩn đánh giá phần mềm nguồn mở quốc tế và Tiêu chuẩn PoF (Principles of Openness).
